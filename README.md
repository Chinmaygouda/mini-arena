# Mini Arena — RANGE FPS

A high-performance first-person shooter built with Three.js and Vite.

## How to Run

### 1. Prerequisites
Ensure you have Node.js (v18+) and npm installed.

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser at the URL shown in terminal (typically `http://localhost:5173/`).

### 4. Build for Production
```bash
npm run build
npm run preview
```

## Weapons & Controls
- **[1] AK-47 Vanguard Assault Rifle**: Full-auto 600 RPM with hollow reflex optic and multi-stage keyframe reload.
- **[2] Tactical M9 Combat Pistol**: Semi-auto sidearm with open U-notch iron sight.
- **[3] Cyclone-9 SMG**: 800 RPM fractional cadence with top Picatinny rail.

### Keybindings
- **W, A, S, D**: Movement
- **Mouse**: Look / Aim
- **Left Mouse Button**: Fire weapon
- **Right Mouse Button**: Aim Down Sights (ADS)
- **R**: Reload
- **1, 2, 3**: Quick weapon switch
- **Shift**: Sprint
- **Space**: Jump
